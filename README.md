# Python Pro Text Workspace

## Project Overview
A fully featured, lightweight desktop Notepad application built entirely in Python using the native `tkinter` GUI framework. This editor scales basic text logging into an advanced development environment, featuring custom text formatting, real-time analytics, and a multi-dimensional search tool.

---

## Key Features

###  Core Functional Toolkit
*   File Management Pipeline: Seamlessly execute standard workspace operations including **New File**, native directories **Open File...**, and data storage **Save As...**.
* **Interactive Clipboard Automation:** Complete system mapping for sequential file manipulation actions like **Undo, Redo, Cut, Copy, and Paste** macros.

###  Advanced Add-ons
*   **Find & Replace Parsing Engine:** An interactive dialog popup module enabling users to scan target string terms across the text block and execute instant global mutations.
*   **Font Customization Selectors:** Integrated toolbar dropdown elements supporting dynamic font family swaps (e.g., Arial, Consolas, Courier) and sequential font-size scale adjustments.
*   **Dynamic Metric Status Bar:** Real-time calculation loops that automatically process and display accurate text data attributes (**Word Count** and **Character Density**) as you type.
*   **High-Contrast Theme Inversion (Dark Mode):** One-click UI layout matrix adjustments switching the workspace into low-light configurations.

## Local Setup & Implementation

### 1. Prerequisites
Ensure you have Python 3 installed on your computer. This application relies purely on standard libraries, meaning **zero external third-party package installation requirements** are necessary to test the source code.

### 2. Launching the App
Clone the repository and run the main entry point via your console terminal:

```bash
# Clone the repository partition
git clone https://github.com

# Move into the workspace folder
cd Python_Pro_Notepad

# Execute the application runtime script
python notepad.py
```
